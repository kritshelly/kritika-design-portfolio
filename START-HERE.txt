YOUR PORTFOLIO

Open index.html in a browser. No install or build step is required.
Current local preview: http://127.0.0.1:4187

Click “Make it yours” to edit your name, contact information, copy, color,
projects, case studies, and project cover images. Save changes to keep edits
in the current browser. Move up changes the project order.

“Export website” downloads an index.html containing your edited portfolio.
Upload that file to a static website host to publish it. Editing a local
browser copy does not automatically update an already-published website.
“Backup JSON” and “Import JSON” let you transfer your content between browsers.
Images uploaded through the editor are resized and embedded in the website.
Google Fonts loads online; system fonts are used when offline.

LONG CASE STUDIES
Open a project and choose “Add images & sections to this project”, or open Make it yours and expand a project. Upload multiple PNG/JPEG/WebP images (8 MB per file), add story sections, titles and captions, and reorder sections with the arrows. Save changes. Case-study images retain their aspect ratio. Large image collections save in this browser using IndexedDB; export a website or JSON backup to keep a portable copy. Clearing browser data removes local saves.
