# Kritika — Design portfolio

Interactive portfolio for product design, UX / UI design, research and strategy, and prototyping.

Live website: https://kritika-design-studio.vercel.app/

## Edit locally

The main website, styling, and interactions are in `index.html`. Original project case studies and their assets are in `imported/`.

Run `python3 -m http.server 4187` from this directory, then open http://localhost:4187/.

The in-page editor saves changes in the current browser. Export and republish to make those edits available to everyone. See `START-HERE.txt` for more details.

The original portfolio source files are retained alongside the current site to preserve previous work.
